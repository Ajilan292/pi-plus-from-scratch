# Setup

This section describes how to prepare the system before the first use, including hardware setup, connection requirements, and safety checks.

---

## Before You Start

Before operating the system, ensure that all components are properly prepared and the environment meets the required conditions.

- Ensure all hardware components are intact and undamaged.
- Do not power on the system before completing all required connections.
- Make sure all cables are correctly connected and securely fastened.
- Ensure the power supply meets the specified requirements.
- Operate the system in a safe and stable environment.

---

## System Components

The system consists of multiple hardware modules that work together to enable operation. The main components include:

- Control unit (main computing and control module)
- Robotic structure (including joints and actuators)
- Power module
- Communication interfaces (USB, Ethernet, and other ports)

Each component must be properly connected before operation.

---

## Hardware Connections

Before powering on the system, complete all necessary hardware connections. The system provides multiple interfaces for communication and power:

- USB ports for peripheral devices
- Ethernet port for network communication
- Power input port for system supply

Ensure:
- All connectors are properly aligned before insertion
- No excessive force is applied during connection
- All cables are securely connected

Improper connections may result in malfunction or damage to the system.

---

## Power Connection

The system must be powered using the specified power supply.

- Use only the recommended power source
- Ensure the power connection is stable before turning on the system
- Do not repeatedly plug or unplug the power cable while the system is running

Before powering on:
- Verify that all hardware connections are complete
- Confirm that the environment is safe for operation

---

## Environment Requirements

The system should be operated in a suitable environment to ensure stability and safety.

- Place the system on a stable and flat surface
- Avoid operation in high humidity or extreme temperature conditions
- Keep the system away from water, dust, and flammable materials
- Ensure sufficient space around the system for safe movement

---

## Pre-Operation Checklist

Before powering on the system, perform the following checks:

- All hardware components are properly installed
- All cables are correctly connected
- Power supply is properly connected
- No visible damage to the system
- The surrounding environment is safe

Only proceed to the next step after all checks are completed.
