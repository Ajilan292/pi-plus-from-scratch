## 图片使用规范

### 命名规范
- 保持原始命名：`product_manual_image{编号}.jpg`
- 编号对应产品手册中的图片顺序
- 在文档中注明图片编号和描述

### 引用方式
在Markdown文档中使用以下格式引用图片：

```markdown
![图片描述](../images/tutorials/product_manual_image2.jpg)
*图片说明文字*
```

## 图片管理

### 添加新图片
1. 将图片文件复制到本目录
2. 更新本指南中的图片列表
3. 在相关文档中添加引用
4. 测试图片显示效果

### 图片优化

- 确保文件大小适中
- 检查显示效果
